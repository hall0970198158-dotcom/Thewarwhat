# ศึกชิงเมือง — เซิร์ฟเวอร์ออนไลน์ (Node + SQLite)

เซิร์ฟเวอร์นี้ทำให้เกมเล่นออนไลน์ได้หลายคน และ **กันโกง** ด้วยหลักการเดียว:
หน้าเว็บส่งมาแค่ "คำสั่ง" (ล่า, โจมตี, คราฟ, ซื้อ ฯลฯ) ส่วน **เซิร์ฟเวอร์เป็นผู้คำนวณผลทั้งหมด** และเก็บสถานะจริงไว้ในฐานข้อมูล SQLite
ผู้เล่นแก้ทอง/ของในเบราว์เซอร์ก็ไม่มีผล เพราะเซิร์ฟเวอร์ไม่เชื่อค่าที่หน้าเว็บส่งมา

- ไม่มี dependency ภายนอก ใช้แค่ Node.js 22.5 ขึ้นไป (มี SQLite ในตัว `node:sqlite`)
- เซิร์ฟเวอร์รันโค้ดเกมชุดเดียวกับหน้าเว็บ (`public/index.html`) จึงไม่ต้องเขียนกติกาเกมซ้ำ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | HTTP server, สมัคร/ล็อกอิน, รับคำสั่ง, บันทึก SQLite, จำกัดความถี่ |
| `engine.js` | โหลดโค้ดเกมจาก `public/index.html` มารันบนเซิร์ฟเวอร์ |
| `public/index.html` | ตัวเกม (ไฟล์เดียวกับใน Artifact) — เซิร์ฟเวอร์จะสั่งให้ทำงานแบบ client อัตโนมัติ |
| `data/game.db` | ฐานข้อมูล (สร้างเองตอนรันครั้งแรก) |

### ตารางในฐานข้อมูล
- `users` — ไอดี, รหัสผ่านแบบ scrypt (ไม่เก็บรหัสจริง), สถานะแบน, เวอร์ชันโทเคน
- `saves` — สถานะเกมทั้งก้อน (JSON) + ชื่อ/อาชีพ/เลเวล/ทอง แยกคอลัมน์ไว้ค้นหาและจัดอันดับ
- `audit` — บันทึกเหตุการณ์น่าสงสัย (เช่น ทองเพิ่มผิดปกติในครั้งเดียว)

## รันในเครื่องตัวเอง

```bash
# ต้องมี Node.js 22.5+  (ตรวจ: node -v)
cp .env.example .env        # แล้วแก้ JWT_SECRET เป็นข้อความสุ่มยาว ๆ
npm start                   # เปิด http://localhost:3000
```

## ขึ้นออนไลน์ด้วย Railway (แนะนำ)

1. สร้าง repository บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ยกเว้น `data/` และ `.env`)
2. เข้า railway.com → **New Project → Deploy from GitHub repo** → เลือก repo นี้
3. แท็บ **Variables** ใส่
   - `JWT_SECRET` = ข้อความสุ่มยาว ๆ (เช่น สร้างจาก `openssl rand -hex 32`)
   - `DB_PATH` = `/data/game.db`
4. แท็บ **Volumes** (หรือคลิกขวาที่ service → Attach Volume) → Mount path = `/data`
   **สำคัญ:** ถ้าไม่ใส่ Volume ข้อมูลผู้เล่นจะหายทุกครั้งที่ deploy ใหม่
5. แท็บ **Settings → Networking → Generate Domain** จะได้ลิงก์ให้คนเข้าเล่น

## ขึ้นออนไลน์ด้วย Render

- ใช้ไฟล์ `render.yaml` ที่เตรียมไว้: **New → Blueprint** แล้วเลือก repo
- ต้องใช้แพ็กเกจที่มี **Disk** (แพ็กเกจฟรีของ Render ไม่มีดิสก์ถาวร ข้อมูลจะหาย)

## สิ่งที่กันโกงได้แล้ว

| การโกง | ผล |
|---|---|
| แก้ทอง/ของ/เลเวล ในเบราว์เซอร์ (DevTools) | ไม่มีผล สถานะจริงอยู่ที่เซิร์ฟเวอร์ |
| ส่งข้อมูลปลอมแนบไปกับคำสั่ง | เซิร์ฟเวอร์อ่านแค่ชื่อคำสั่ง ไม่รับค่าสถานะจากหน้าเว็บ |
| ยิงคำสั่งรัว ๆ ด้วยสคริปต์/บอท | จำกัดเฉลี่ย 12 คำสั่ง/วินาทีต่อคน เกินได้รหัส 429 |
| เร่งออโต้ล่า/ฟื้นพลังงานเร็วกว่าปกติ | ใช้เวลาของเซิร์ฟเวอร์ และ tick ถี่กว่า 0.5 วินาทีไม่นับ |
| เดารหัสผ่าน | ล็อกอินได้ 20 ครั้ง/15 นาทีต่อ IP, สมัครได้ 5 ครั้ง/ชั่วโมงต่อ IP |
| ปลอมโทเคน | โทเคนเซ็นด้วย HMAC-SHA256 + `JWT_SECRET` ปลอมไม่ได้ |
| ขโมยโทเคนแล้วใช้ต่อ | กด "ออกจากระบบ" แล้วโทเคนเก่าทุกเครื่องใช้ไม่ได้ |

## ข้อจำกัดของรุ่นนี้

- **แชท, อันดับ PvP ผู้เล่นจริง, สงครามสี่ฝ่ายแบบออนไลน์** ยังใช้ระบบของ Artifact อยู่ บนเซิร์ฟเวอร์นี้จะยังไม่ทำงาน (PvP สู้กับคู่ต่อสู้ AI ได้ตามปกติ) — วางแผนย้ายในรอบถัดไป
- ยังไม่มีหน้าแอดมิน การแบนทำได้โดยตั้ง `banned=1` ในตาราง `users`
- บอทที่กดเหมือนคนจริงยังเล่นแทนคนได้ (เหมือนเกมออนไลน์ทั่วไป) แต่จะไม่ได้เปรียบเกินคนที่เล่นมือ

## อัปเดตเกม

แทนที่ `public/index.html` ด้วยไฟล์เกมรุ่นใหม่ แล้ว deploy ใหม่ ข้อมูลผู้เล่นใน `game.db` ยังอยู่
(ไฟล์เกมต้องเป็นรุ่นที่มีโหมด `server` / `client` แล้ว คือรุ่น V111 ขึ้นไป)

## API (สำหรับนักพัฒนา)

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| POST | `/api/register` | `{username, password}` → `{token}` |
| POST | `/api/login` | `{username, password}` → `{token}` |
| POST | `/api/logout` | ยกเลิกโทเคนทุกเครื่อง |
| GET | `/api/state` | สถานะเกมปัจจุบัน |
| POST | `/api/act` | `{a, p, inp}` ส่งคำสั่ง 1 ครั้ง → สถานะใหม่ + เอฟเฟกต์ |
| POST | `/api/tick` | เดินเวลา (ฟื้นพลัง/ออโต้) ทุก ~0.9 วินาที |
| GET | `/api/top` | อันดับเลเวลสูงสุด 50 คน |
| GET | `/api/health` | ตรวจว่าเซิร์ฟเวอร์ทำงาน |
